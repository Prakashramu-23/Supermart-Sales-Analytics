# Supermart Grocery Sales Analytics & Profit Prediction

## Overview
This project analyzes Supermart Grocery Sales data and predicts profit using Machine Learning.

## Dataset Features
- Order ID
- Customer Name
- Category
- Sub Category
- City
- Order Date
- Region
- Sales
- Discount
- Profit
- State

## Objectives
- Perform Data Cleaning
- Conduct Exploratory Data Analysis (EDA)
- Build Profit Prediction Models
- Create Power BI Dashboard
- Deploy Streamlit Application

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- XGBoost
- Power BI
- Streamlit

## Machine Learning Models
- Linear Regression
- Random Forest Regressor
- XGBoost Regressor

## Evaluation Metrics
- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## Dashboard Features
- KPI Cards
- Sales by Category
- Profit by Category
- Monthly Sales Trends
- Quarterly Sales Trends
- Top 10 Cities by Sales
- Regional Analysis
- Discount vs Profit Analysis
